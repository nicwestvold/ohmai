# ohmai pi extension, format v1

Status files as written by `Sources/OhmaiPiAdapter/Resources/ohmai.ts` (format `v: 1`).
ohmai owns this format. Values are placeholders. `busy-unsaved.json` is a session before
pi has written its first message (no session id or file yet).

If the extension's format changes, bump `v` and add an `ohmai-pi-v<n>/` directory here.
